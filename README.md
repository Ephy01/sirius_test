# Sirius Test — Dice & Chess

Интерактивный фронтенд-прототип платформы интеллектуальных отборов для школьников 9–11 классов.

В демо участник:

- открывает миссию Dice & Chess;
- решает вероятностную задачу;
- при желании обсуждает условие с ИИ-навигатором;
- отправляет решение через то же окно чата;
- получает содержательную обратную связь;
- переходит в следующую ветку, выбранную по результату ответа.

## Запуск

Из папки проекта:

```bash
python3 -m http.server 8000
```

После этого открыть `http://localhost:8000`.

Прототип полностью работает в браузере и не отправляет данные на сервер. События текущей демонстрационной сессии сохраняются локально в `localStorage`.

## Ветки

- `main` — описание проекта;
- `enrollement_test` — исходное тестовое задание;
- `dev` — текущий фронтенд-прототип.
