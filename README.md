# Прототип квеста с ИИ советником - тестовое задание

### Для технической реализации использовался Claude - подробнее в мотивационном письме.


Прототип квеста с ИИ-советником: участник проходит день операционного директора доставки, а платформа оценивает не ответы, а процесс работы с ИИ. Запуск: из папки проекта выполнить `python3 -m http.server 8000` и открыть `http://localhost:8000` — через статический сервер. 

Процессные метрики участнику не показываются: после финального экрана они печатаются в консоль браузера (F12 → Console, строки с префиксом `[research]` — балл, покрытие и полный JSON по компонентам; лог повторяется при каждом обновлении финальной страницы), а их копия накопительно сохраняется в localStorage под ключом `delivergo:research` (DevTools → Application → Local Storage).
