# Sirius Gate

Рабочий вертикальный срез платформы интеллектуальных отборов Сириуса.
Реализована серверная цепочка:

`контест → участник → персональный код → попытка → задача → журнал событий`.

Организатор создаёт контест «Шахматный мир», настраивает семейства Chess960,
Dice & Chess и Penultima, добавляет участников, выпускает коды и публикует
контест. Участник входит по выданному коду, отдельной кнопкой запускает
серверную попытку и работает в двухзонной среде: задача слева, чат-команды
справа.

В текущем срезе подключено первое формально проверяемое семейство —
валидация расстановок Chess960. Задачи воспроизводимо создаются из seed
попытки, номера задачи и версии генератора. Правильность вычисляет серверный
код, а участник получает только нейтральное подтверждение. В append-only
журнал попадают запуск попытки, генерация, ответ, оценивание, пропуск и
истечение времени.

Команды участника:

- `/help` — справка;
- `/answer <текст>` — зафиксировать ответ;
- `/skip` — пропустить задачу;
- `/next` — получить следующую задачу после ответа или пропуска.

## Запуск

Сначала API:

```bash
cd backend
python3 -m venv .venv
.venv/bin/pip install -e '.[test]'
.venv/bin/uvicorn app.main:app --reload --port 8001
```

Затем frontend из корня репозитория:

```bash
npm install
npm run dev
```

Vite запустит приложение на `http://127.0.0.1:4173` и проксирует `/api` в
FastAPI на порту `8001`.

## Локальный доступ

- код организатора: `ORBIT-ADMIN`;
- коды участников создаются внутри конструктора контеста.

В браузере хранится только подписанная серверная сессия и маска кода. Открытые
коды участников возвращаются один раз при генерации; в базе сохраняется
HMAC-SHA256.

## Проверка

```bash
npm run check
npm run build
cd backend && .venv/bin/python -m pytest
```

Предыдущий консольный прототип полностью сохранён в
`legacy/console-prototype`.

Dice & Chess и Penultima уже доступны в конструкторе как конфигурация
контеста, но их генераторы и проверяющие модули ещё не подключены.
