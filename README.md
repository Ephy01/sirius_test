# Sirius Gate

UI-прототип платформы интеллектуальных отборов Сириуса. В первой итерации
реализован вход по коду и два ролевых пространства:

- организатор попадает в пустой дэшборд создания контестов;
- участник сразу открывает миссию Dice & Chess с задачей и консолью.

## Запуск

```bash
npm install
npm run dev
```

Vite запустит приложение на `http://127.0.0.1:4173`.

## Демо-коды

- участник: `SIRIUS-2026`;
- организатор: `ORBIT-ADMIN`.

Роль хранится только в `sessionStorage`. Настоящая серверная авторизация будет
подключена после согласования API Identity Service.

## Проверка

```bash
npm run check
npm run build
```

Предыдущий консольный прототип полностью сохранён в
`legacy/console-prototype`.
